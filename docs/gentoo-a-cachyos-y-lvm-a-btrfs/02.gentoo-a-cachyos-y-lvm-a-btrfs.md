### Introducción: El fin de la era de la compilación infinita

Como usuario de Gentoo, el control es vital. Pero la realidad en Venezuela —con cortes eléctricos que no perdonan y tiempos de compilación que consumen días en una laptop— me ha llevado a buscar una alternativa que mantenga el rendimiento pero priorice la eficiencia. 

**CachyOS** es la respuesta: binarios optimizados y un kernel agresivo. Para que el cambio valga la pena, vamos a jubilar el esquema de LVM/XFS y abrazar la flexibilidad y resiliencia de **Btrfs**.

---

### 1. El Cambio de Paradigma: ¿Por qué Btrfs?

En mi configuración anterior de LVM, el espacio estaba segmentado en muros rígidos. En Btrfs, usamos **Subvolúmenes**. 

*   **¿Qué es el símbolo `@`?** Es una convención. No es obligatorio para el kernel, pero herramientas como `grub-btrfs` y `Timeshift` lo buscan para automatizar los snapshots. 
*   **Adiós a los límites:** Todos los subvolúmenes comparten un "pool" de almacenamiento. El espacio fluye hacia donde se necesita sin usar `lvextend`.

---

### 2. Particionado Manual (Vía SSH)
Una vez conectados por SSH al entorno Live de la laptop, procedemos a preparar el NVMe de 512GB (asumiremos `/dev/nvme0n1`).

#### Limpieza Total y Creación de Particiones Físicas
```bash
# Limpiar tablas previas y crear una nueva GPT
sudo sgdisk -Z /dev/nvme0n1
sudo sgdisk -o /dev/nvme0n1
```

```bash
# 1. EFI (1GB) - Para no sufrir nunca por espacio en el boot
sudo sgdisk -n 1:0:+1G -t 1:ef00 -c 1:"EFI" /dev/nvme0n1

# 2. Btrfs Pool (El resto del disco)
sudo sgdisk -n 2:0:0 -t 2:8300 -c 2:"CACHYOS" /dev/nvme0n1

# Formateo de particiones
sudo mkfs.vfat -F32 /dev/nvme0n1p1
sudo mkfs.btrfs -L CACHYOS -f /dev/nvme0n1p2
```

### 3. Estructura de Subvolúmenes y Montaje
Montamos el pool temporalmente, creamos los subvolúmenes y volvemos a montar con optimizaciones para NVMe (zstd, noatime, discard=async).

```bash
# Montaje temporal para crear subvolúmenes lógicos
sudo mount /dev/nvme0n1p2 /mnt
sudo btrfs subvolume create /mnt/@
sudo btrfs subvolume create /mnt/@home
sudo btrfs subvolume create /mnt/@log
sudo btrfs subvolume create /mnt/@cache
sudo btrfs subvolume create /mnt/@tmp
sudo btrfs subvolume create /mnt/@containerd
sudo btrfs subvolume create /mnt/@docker
sudo umount /mnt

# Montaje definitivo de la raíz con optimizaciones
sudo mount -o subvol=@,compress=zstd,noatime,discard=async /dev/nvme0n1p2 /mnt

# Crear estructura de directorios y montar el resto
sudo mkdir -p /mnt/{boot,home,var/log,var/cache,var/tmp}
sudo mount /dev/nvme0n1p1 /mnt/boot
sudo mount -o subvol=@home,compress=zstd,noatime,discard=async /dev/nvme0n1p2 /mnt/home
sudo mount -o subvol=@log,compress=zstd,noatime,discard=async /dev/nvme0n1p2 /mnt/var/log
sudo mount -o subvol=@cache,compress=zstd,noatime,discard=async /dev/nvme0n1p2 /mnt/var/cache
sudo mount -o subvol=@tmp,compress=zstd,noatime,discard=async /dev/nvme0n1p2 /mnt/var/tmp
sudo mkdir -p /mnt/var/lib/containerd 
sudo mkdir -p /mnt/var/lib/docker
sudo mount -o subvol=@containerd,compress=zstd,noatime,discard=async /dev/nvme0n1p2 /mnt/var/lib/containerd
sudo mount -o subvol=@docker,compress=zstd,noatime,discard=async /dev/nvme0n1p2 /mnt/var/lib/docker
```

### 4. Instalación del Sistema Base (Bootstrap)
Usamos basestrap para desplegar el sistema. Es el equivalente al desempaquetado del stage3 en Gentoo.

```bash
sudo pacstrap -K /mnt base base-devel linux-cachyos linux-cachyos-headers btrfs-progs networkmanager nano vim

# Generar FSTAB
sudo genfstab -U /mnt | sudo tee /mnt/etc/fstab
```

### 5. Configuración del Sistema (Chroot)
Entramos al nuevo sistema para los ajustes finales.
```bash
sudo arch-chroot /mnt

# Zona horaria (Venezuela)
ln -sf /usr/share/zoneinfo/America/Caracas /etc/localtime
hwclock --systohc

# Locales
echo "es_VE.UTF-8 UTF-8" >> /etc/locale.gen
echo "en_US.UTF-8 UTF-8" >> /etc/locale.gen
locale-gen
echo "LANG=es_VE.UTF-8" > /etc/locale.conf

# Hostname y Hosts
echo "laptop" > /etc/hostname
cat <<EOF> /etc/hosts
127.0.0.1   localhost
::1         localhost
127.0.1.1   laptop.localdomain   laptop
EOF

# Usuarios y Permisos
# Clave de root
passwd 

# Crear usuario personal
useradd -m -G wheel,storage,power -s /bin/zsh usuario
passwd usuario

# Habilitar Sudo (Descomentar la línea %wheel ALL=(ALL:ALL) ALL)
EDITOR=nano visudo

```
### 6. Bootloader y Resiliencia (GRUB)
Instalamos GRUB con soporte para snapshots de Btrfs.
```bash
pacman -S grub efibootmgr grub-btrfs inotify-tools
grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=CachyOS
grub-mkconfig -o /boot/grub/grub.cfg

# Activar NetworkManager para el próximo reinicio
systemctl enable NetworkManager
```

### 7. Finalización
Salimos del entorno chroot, desmontamos las particiones de forma segura y reiniciamos.

exit
sudo umount -R /mnt
sudo reboot
